## 2. Supabase 환경 설정

### GitHub Secrets 확인
기존에 등록된 시크릿 3개 확인:
- `VITE_SUPABASE_URL` — Supabase 프로젝트 URL
- `VITE_SUPABASE_ANON_KEY` — Supabase anon public 키
- `VITE_SITE_URL` — 배포 URL (OAuth redirect용으로 미리 등록, 코드에서 미사용 상태)

### .env.local 실제 키 입력
로컬 개발 및 Edge Function 테스트를 위해 `.env.local`에 실제 Supabase URL / anon key 입력.
`.env.local`은 `.gitignore` 처리되어 있어 리포지토리에 올라가지 않음.

## 3. AI 챗봇 구현

### 아키텍처 설계
```
사용자 입력
    ↓
ChatBot.jsx (React)
    ↓ fetch (SSE streaming)
Supabase Edge Function (chat)  ← SOLAR_API_KEY / OPENAI_API_KEY
    ↓
Upstage Solar API 또는 OpenAI API
    ↓
스트리밍 응답 반환
```

- API 키는 Supabase Edge Function secrets에만 저장 (클라이언트 노출 없음)
- `--no-verify-jwt` 플래그로 비로그인 사용자도 챗봇 이용 가능

### 파일 생성

#### `supabase/functions/chat/index.ts`
- Deno 기반 Supabase Edge Function
- `provider` 파라미터로 `solar` / `openai` 분기
  - Solar: `https://api.upstage.ai/v1/chat/completions` + `solar-pro` 모델
  - OpenAI: `https://api.openai.com/v1/chat/completions` + `gpt-4o-mini` 모델
- `stream: true` 설정으로 SSE 스트리밍 응답 pass-through
- 곁에 서비스 맞춤 시스템 프롬프트 내장 (서비스 목록, 가격, 이용 방법, 답변 규칙)
- CORS 헤더 처리 (OPTIONS preflight 포함)

#### `src/components/ChatBot.jsx`
- 플로팅 원형 버튼 (우하단 고정)
- 클릭 시 채팅 팝업 창 슬라이드업 오픈
- Solar / GPT 토글 버튼
- 웰컴 메시지 타이핑 효과 (첫 오픈 시 1회)
- 빠른 질문 4개 버튼 (첫 대화 전 노출)
- 실시간 스트리밍 텍스트 출력 (SSE ReadableStream 파싱)
- AI 메시지 옆 "곁" 아바타
- 모바일(< 640px) 전체화면 자동 전환

#### `src/App.jsx` 수정
- `<ChatBot />` 전체 페이지에 추가
- 기존 FloatingBtn(도움 신청) 위치를 `bottom: 7rem`으로 올려 겹침 방지

### Supabase CLI로 Edge Function 배포
```bash
npx supabase login --token <access_token>
npx supabase link --project-ref exvcaeidzxlwxfznalsr
npx supabase functions deploy chat --no-verify-jwt
```

> `npx supabase login` 은 TTY 환경이 아니면 브라우저 플로우가 동작하지 않음.
> `--token` 플래그로 Supabase 대시보드에서 발급한 액세스 토큰을 직접 전달해야 함.

## 4. GitHub Pages 배포 환경 정상화

### 문제 상황
`https://seowoo92.github.io/rest06/` 접속 시 흰 화면.
브라우저 콘솔에서 `GET /src/main.jsx 404` 확인.
빌드된 파일이 아닌 개발용 `index.html`(`<script src="/src/main.jsx">`)이 서빙되고 있었음.

### 원인 분석
GitHub Pages 설정이 **"Deploy from a branch"** → `main` 브랜치로 되어 있어
소스 파일이 그대로 서빙되고 있었음.
기존 `peaceiris/actions-gh-pages@v3` 방식은 `gh-pages` 브랜치에 빌드 결과를 push하지만,
Pages 소스가 `main`이라 무시되고 있었음.

### 해결 과정

**시도 1** — `peaceiris` 워크플로우에 `permissions: contents: write` 추가
→ gh-pages 브랜치 배포는 성공했으나 Pages가 여전히 main을 서빙해서 실패

**시도 2** — 워크플로우를 공식 GitHub Actions Pages 방식으로 전환
```yaml
permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  build:
    - uses: actions/upload-pages-artifact@v3
      with:
        path: ./dist
  deploy:
    - uses: actions/deploy-pages@v4
```
→ 워크플로우 자체는 성공했으나 Pages 설정이 "Deploy from a branch"여서 여전히 실패

**시도 3 (해결)** — GitHub 리포지토리 Settings → Pages → Source를 **"GitHub Actions"** 로 변경
→ 빈 커밋으로 재배포 트리거 후 정상 서빙 확인

### 최종 워크플로우 구조 (`.github/workflows/deploy.yml`)
```
push to main
    → build (npm ci → npm run build, Supabase secrets 주입)
    → actions/upload-pages-artifact (dist/ 업로드)
    → actions/deploy-pages (GitHub Pages 배포)
```

## 5. 챗봇 디자인 고도화

### 애니메이션 추가
| 효과 | 구현 방법 |
|------|-----------|
| 팝업 슬라이드업 | `chatSlideUp` — translateY + scale spring |
| 버튼 pulse ring | 이중 `pulseChat` keyframe (0.7s 위상 차) |
| 메시지 등장 | `msgSlide` — fadeIn + translateY |
| 타이핑 도트 | `chatDot` — scale bounce, 0.18s 간격 순차 |
| 전송 버튼 클릭 | `sendBounce` — scale 0.82 → 1.18 → 1, ref 강제 리플로우로 반복 재생 |
| 커서 깜빡임 | `blink` — step-end |

### 스트리밍 적용
`supabase.functions.invoke()` 대신 `fetch()` + `ReadableStream` 직접 사용.
- SSE 청크 파싱: `data: {...}` 라인 추출 → `choices[0].delta.content` 누적
- 첫 청크 도착 시 `loading` false 전환, 이후 청크는 마지막 메시지에 append
- Edge Function도 `stream: true` 로 변경하여 AI API 스트림 pass-through

### 기타 UI 개선
- 헤더 반투명 도트 텍스처 오버레이 (`radial-gradient` 14px grid)
- 입력창 포커스 시 primary 컬러 테두리 + ring glow
- 빠른 질문 버튼 호버 시 배경 fill 전환
- 로딩 중 헤더에 "답변 작성 중..." 텍스트 표시

## 6. 풍선 도움말 (Tooltip Bubble)

### 요구사항
챗봇 버튼 옆에 항상 노출되는 말풍선 도움말. 위아래로 떠있는(floating) 효과.

### 구현
- 버튼 래퍼 내부에 `position: absolute, right: 66px` 으로 배치
- 말풍선 꼬리: CSS `::before` (테두리색) + `::after` (배경색) 이중 삼각형
- `bubbleFloat` keyframe: `translateY(0) → translateY(-7px)` 2.8초 주기 ease-in-out
- 채팅창 열리면 말풍선 자동 숨김 (`!isOpen` 조건부 렌더)
- 말풍선 클릭 시 채팅창 열림

```css
@keyframes bubbleFloat {
  0%, 100% { transform: translateY(0);    }
  50%      { transform: translateY(-7px); }
}
```
